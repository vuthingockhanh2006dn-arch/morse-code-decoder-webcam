# Report Outline / Đề cương báo cáo

Figures and tables referenced below are generated by the scripts in `src/`.

## Chương 1. Tổng quan đề tài
- Lý do chọn đề tài, mục tiêu, phạm vi (2 chế độ: Morse và ký hiệu tĩnh), đối tượng sử dụng, sản phẩm dự kiến.
- Phân biệt: nhận diện ký hiệu rời rạc ≠ dịch ngôn ngữ ký hiệu.

## Chương 2. Cơ sở lý thuyết và công trình liên quan
- Mã Morse quốc tế, bảng tra (`src/morse_decoder.py`).
- Bảng chữ cái ký hiệu được chọn cho chế độ ký hiệu tĩnh.
- MediaPipe Hands: 21 landmarks; khoảng cách Euclid chuẩn hóa.
- KNN, SVM (RBF), Random Forest; máy trạng thái hữu hạn (FSM).

## Chương 3. Thu thập và xử lý dữ liệu
- Nguồn, quy trình thu (`data/dataset_description.md`).
- Thống kê: `data/processed/<task>/dataset_stats.json`, hình `figures/<task>_class_distribution.png`.
- Làm sạch, chuẩn hóa 63 đặc trưng, chia 70/15/15 theo phiên.

## Chương 4. Phân tích và thiết kế hệ thống
- Yêu cầu chức năng / phi chức năng.
- Kiến trúc luồng xử lý: webcam → MediaPipe → classifier/rule → smoothing → FSM → Morse lookup → Đầu ra văn bản (Text Output).
- Cơ chế chống nhập lặp: majority vote, release_frames, trạng thái LOCKED, quay về IDLE.

## Chương 5. Xây dựng và thực nghiệm
- Chọn siêu tham số trên Validation: `reports/<task>_validation_results.csv`.
- Kết quả trên Test: `reports/<task>_test_results.md`, `<task>_<algo>_classification_report.txt`.
- Ma trận nhầm lẫn: `figures/<task>_<algo>_confusion_matrix.png`, phân tích các cặp dễ nhầm.
- Thử nghiệm thực tế (điền bảng bên dưới).

### Bảng thử nghiệm thực tế (end-to-end)
| Người thử | Ánh sáng | Nền | Khoảng cách | Chuỗi mục tiêu | Chuỗi nhận được | Ký tự đúng / tổng | Nhập lặp | Mất ký hiệu | FPS |
|---|---|---|---|---|---|---|---|---|---|
| user_01 (cũ) | phòng | đơn giản | 50 cm | SOS | | | | | |
| user_04 (mới) | yếu | phức tạp | 80 cm | HELLO | | | | | |

Character accuracy = (số ký tự đúng) / (tổng ký tự mục tiêu); word accuracy = (số từ đúng hoàn toàn) / (tổng số từ).

## Chương 6. Kết luận và hướng phát triển
- Kết quả đạt được, hạn chế (ánh sáng, góc nghiêng, che khuất).
- Hướng phát triển: ký hiệu động (LSTM/Transformer trên chuỗi landmark), hai tay, nhiều người dùng, hiệu chỉnh ngưỡng theo người dùng.
